Staff guide

ATF Discord Bot Commands

Use this guide to create tracked Invites, retrieve previous Requests, check Invite health, clean up unused capacity, and export member data.

Access Terms Command index Create Invites Retrieve Requests Health and Capacity Cleanup Exports

Access and Visibility

  • All commands are slash commands used in Discord.
  • Only staff with the configured Admin or Mod role can use these commands.
  • Commands may be restricted to designated bot channels.
  • Command replies are private to the staff user. Some commands also attach CSV files or send a DM receipt.
  • Invites created by the bot point to the configured rules channel.

Terms Used in This Guide

Invite

A Discord invite created or tracked by the bot. Prefer this term over "link" unless you are referring to the full URL.

Invite Code

The unique code inside a Discord invite URL, such as abc123 in https://discord.gg/abc123.

Request ID

The human-readable ID recorded when staff create one or more Invites, such as 2026-04-30-abc.

Invite Role

The role the bot auto-assigns when a member joins through a tracked Invite. Current values are student and mentor.

Live Invite

An Invite that can still be used. It is not expired and has not reached its maximum uses.

Dead Invite

An Invite that can no longer be used because it expired or reached its maximum uses.

Create Invites

/invite-create

Single Invite

Use this when you need one tracked Invite for a person or group.

/invite-create reason:<text> [max-uses:<number>] [max-age:<days>] [role:student|mentor]
Option Required Default Notes
reason Yes None Cannot be empty. Use a clear reason staff can recognize later.
max-uses No 1 Positive integer only.
max-age No 7 days Positive integer in days. 0 is not allowed.
role No student Choose student or mentor.

You receive: a private reply with the Invite URL, Request ID, reason, and Invite Role. The bot also sends you a DM receipt with the Request ID, reason, and Invite Role.

/invite-create-bulk

Bulk Invites

Use this when you need many tracked Invites from a CSV file.

/invite-create-bulk file:<csv attachment> [max-uses:<default max uses>]
Input Rule
File Must be a .csv attachment with a header row and at least one data row.
Rows Maximum 1000 data rows. Split larger files before uploading.
reason column Required. New Invite rows must have a non-empty reason.
max-uses command option Optional default for rows without their own max-uses. Defaults to 50.

CSV Columns

Column Required Default Notes
reason Yes None Why the Invite is being created.
max-uses No 50, or the command option value Positive integer. Use -1 to use the default when this column is present.
max-age No 7 days Positive integer in days. Use -1 to use the default. 0 is not allowed.
role No student Use student or mentor.
invite-link No Blank If present, the row is skipped and the existing Invite URL is preserved in the output CSV.

You receive: progress updates, a final summary, an output CSV attachment, and a DM receipt. The output CSV includes generated Invite URLs and preserves existing Invite URLs.

If the bot sees 3 consecutive Invite creation errors, it stops the bulk run and reports the first error. A Cancel button can stop the run after the current row finishes.

Retrieve Previous Requests

/invite-get

Lookup

Use this when you have a Request ID and need to look up the original Invite Request.

/invite-get request-id:<request id>
  • Single Requests return the Invite URL, reason, Invite Role, requester, and request time.
  • Bulk Requests return Request details and the bulk output CSV when it is available.
  • If no Request matches the ID, the bot tells you that no Invite Request was found.

Check Health and Capacity

/invite-status

Invite Health

Use this when you need to know whether a specific Invite still works.

/invite-status invite:<invite code or URL>
  • Accepts either an Invite Code like abc123 or a URL like https://discord.gg/abc123.
  • Returns status, uses, expiration, channel, and Invite Role if the Invite is tracked by the bot.
  • Status values are Active, Fully used, or Expired.

/invite-capacity

Capacity

Use this before large bulk runs or when Invite creation starts failing.

/invite-capacity
  • Shows total server Invites and the nominal Discord limit of 1000.
  • Shows how many tracked bot-created Invites are live or dead.
  • Available capacity can be 0 or negative when the server is at or over the nominal limit.

Clean Up Invites

/invite-cleanup

Destructive

Use this to delete selected Invites from Discord and free Invite Capacity.

/invite-cleanup [mode:<cleanup mode>] [confirm:i-know-what-im-doing-atf-bot]

Non-default modes are destructive. They require the exact confirm value i-know-what-im-doing-atf-bot. Deleted Invites stop working immediately.

Mode Deletes Confirm required
All dead bot invites Tracked bot-created Invites that are expired or fully used. No. This is the default.
All bot invites All tracked bot-created Invites, live or dead. Yes
All dead invites All dead Invites on the server, including human-created Invites. Yes
All invites Every Invite on the server, including live and human-created Invites. Yes
  • The bot reports how many Invites it deleted and the capacity afterward.
  • If deletion fails for some Invites, the bot lists the first errors.
  • Cleanup is blocked while a bulk Invite process is running.

Export Members

/all-member-export

CSV Export

Use this to export current non-bot server members as a CSV attachment.

/all-member-export full
/all-member-export filtered unit:hour|day|week|month [amount:<number>]
Subcommand Exports Filename
full All non-bot members, sorted by join date. members-full.csv
filtered Non-bot members who joined within the recent time window. For example, members-last-1-week.csv.

Filtered exports require unit. The optional amount defaults to 1 and must be a positive integer.

CSV columns are username, displayName, userId, joinedAt, roles, inviteCode, inviteRole, requestedBy, and reason.

Quick Troubleshooting

  • No permission: you need the configured Admin or Mod role.
  • Wrong channel: run the command in a designated bot channel.
  • Bulk validation failed: fix the CSV errors shown in the reply and upload again.
  • Not enough capacity: run /invite-capacity, then use default /invite-cleanup if dead bot Invites exist.
  • Invite not found: it may have expired, been fully used and deleted, or been deleted manually.
  • Output CSV unavailable: use the CSV attached to the original bulk reply if you still have it.
